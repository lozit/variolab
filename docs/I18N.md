# Internationalization (i18n) — Variolab – A/B Testing

**Living** strategy for multilingual support. For the **why** behind structural choices → see `docs/decisions/`.

> Two distinct concerns: (1) **UI string translation** (the admin interface) and (2) **multilingual content matching** (one experiment matching `/fr/promo/`, `/en/promo/`…). Both are covered below.

## UI string translation

- **Text domain**: `variolab-ab-testing` (= plugin slug).
- **Source strings are always in English** (repo language policy). Translations live as `.po`/`.mo` under `languages/` if anyone provides them.
- Every user-facing string uses `__()` / `_e()` / `esc_html__()` / `esc_html_e()` with the text domain; placeholders carry `translators:` comments; plurals use `_n()`.
- **No manual `load_plugin_textdomain()`**: wordpress.org auto-loads translations for hosted plugins since WP 4.6; the `Text Domain` + `Domain Path: /languages` headers are declared so JIT loading works. `languages/index.php` ("Silence is golden") satisfies the folder requirement.

## Multilingual content matching (WPML / Polylang)

- `Abtest\MultiLanguage` auto-detects WPML/Polylang and **strips the leading `/{lang}/` prefix** from the request path before matching, so a single experiment with `test_url = /promo/` matches `/fr/promo/`, `/en/promo/`, `/de/promo/`, etc.
- Compound slugs supported (`pt-br`, `en-us`). Stripping only at the **leading** position — `/blog/fr/x/` is not stripped.
- Public filter **`abtest_request_path`** lets custom setups rewrite the path the matcher sees. Opt-out: `remove_filter('abtest_request_path', [\Abtest\MultiLanguage::class, 'strip_language_prefix'])`.
- Covered by 9 unit tests + a simulated WPML e2e in wp-env.

## Localized formats

- Dates in the admin use WordPress's locale-aware helpers (`human_time_diff`, site date format). Numbers/rates are rendered with the site locale.

## Translation process

New English source strings are added in code; the `.pot` can be regenerated from the source; community `.po` files drop into `languages/`. No strings are committed in any language other than English (only chat may be French).
